# Noor Scholar - Next.js

Free academic search engine built on OpenAlex.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm start
```

## Deploy
Vercel: import this folder. Netlify: build command `npm run build`.

## SEO
Each page has metadata, sitemap.ts and robots.ts included.
